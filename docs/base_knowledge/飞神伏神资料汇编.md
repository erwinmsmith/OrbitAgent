## 三、飞神伏神的定义与取法

### 1. 《火珠林》：本宫在下为伏，旁宫在上为飞

《火珠林》“六亲根源”：

```text
卦定根源，六亲为主；
又究旁通，五行而取。
```

注中说明：

```text
盖本宫在下为伏之六亲，旁宫在上为飞之六亲。
先看六亲之下，后看六亲之上，所乘得何爻，而辨吉凶存亡也。
```

又说：

```text
本宫之六亲在飞象之下，为之亲王，为之伏神。
旁宫之飞象加伏神之上，为飞象。
知飞伏二爻之来历，然后可与言八卦、六亲矣。
```

位置：`原典/火珠林.md:149-165`

可入库规则：

- 飞伏不是任意附会，而是依卦宫、本宫六亲、旁宫飞象而来。
- 本宫隐藏六亲为伏神。
- 显在其上的本卦爻为飞神。

### 2. 《增删卜易》：用神不现，寻宫首卦

《增删卜易》“飞伏神章第二十八”：

```text
若用神不现，即以日月为用神，倘日月非用神者，则于宫首卦寻之，
因本宫首卦，父子财官六亲俱全之故耳。
```

位置：`原典/增删卜易.md:1067-1069`

天风姤例：

```text
此卦寅木妻财在二爻，即以此寅木伏于姤卦亥水之下，
姤卦二爻之亥水即为飞神，寅木妻财即为伏神，
亥水而生寅木，谓之飞来生伏得长生。
```

位置：`原典/增删卜易.md:1076-1083`

天山遁例：

```text
乾为天初爻之子水子孙以伏于遁卦初爻辰土之下，
辰土即是飞神，子水便是伏神，
此乃飞来克伏，谓之飞克，伏神遭克害，名为伏神受制。
```

位置：`原典/增删卜易.md:1090`

可入库规则：

1. 本卦用神不现时，先看日月是否可作为现实用神参考。
2. 日月也非用神时，在本宫首卦寻找对应六亲。
3. 本宫首卦对应爻为伏神。
4. 本卦同爻位显现爻为飞神。

### 3. 《卜筮正宗》：变爻有用神，不必寻伏

《卜筮正宗》“伏神正传第六”：

```text
夫伏神者，谓卦之有缺用神，纔看用神伏于何爻之下。
```

位置：`原典/卜筮正宗.md:996-997`

《卜筮正宗》“辟易林补遗伏神之谬”：

```text
凡卦中用神不出现，查变爻有不必寻伏神矣。
倘变爻又无，然后查用神伏于何爻之下，看有提拔没有。
```

位置：`原典/卜筮正宗.md:1122`

可入库规则：

1. 本卦缺用神，才论伏神。
2. 若变爻已有用神，不必另寻伏神。
3. 本卦、变爻均无，再查伏神。
4. 查得伏神后，还要看是否有“提拔”条件。

### 4. 《易隐》：六爻不见用象，方取伏神

《易隐》“定飞伏神法”：

```text
飞伏者往来隐显之神也。
飞为已往，伏为将来。
若卦内用神不空不破，不必更取伏神。
惟六爻不见用象者方取伏神推之。
```

位置：`原典/易隐_古籍典藏.md:486-492`

可入库规则：

- 卦内已有可用之神时，不应滥取伏神。
- 六爻不见用象，才取伏神推断。

## 四、飞伏生克关系

### 1. 《卜筮正宗》飞伏生克吉凶歌

《卜筮正宗》：

```text
伏克飞神为出暴飞，来克伏反伤身，
伏去生飞名泄气，飞来生伏得长生，
爻逢伏克飞无事，用见飞伤伏不宁，
飞伏不和为助伏藏出现审来因。
```

位置：`原典/卜筮正宗.md:251-253`

可入库关系：


| 飞伏关系 | 古籍用语    | 规则含义       |
| ---- | ------- | ---------- |
| 伏克飞  | 伏克飞神为出暴 | 伏神克飞神      |
| 飞克伏  | 飞来克伏反伤身 | 飞神克伏神，伏神受伤 |
| 伏生飞  | 伏去生飞名泄气 | 伏神生飞神，伏神泄气 |
| 飞生伏  | 飞来生伏得长生 | 飞神生伏神，伏神得生 |


### 2. 《易隐》同类表述

《易隐》：

```text
伏克飞为出暴，飞克伏则伤身。
伏生飞曰泄气，飞生伏而叨生。
飞伏比和，则相助而吉也。
```

位置：`原典/易隐_古籍典藏.md:492-494`

补充关系：


| 飞伏关系 | 古籍用语       | 规则含义          |
| ---- | ---------- | ------------- |
| 飞伏比和 | 飞伏比和，则相助而吉 | 飞伏同五行或同气，比和相助 |


## 五、伏神有用与无用

### 1. 《增删卜易》有用伏神六条

《增删卜易》：

```text
伏神有用者有六：
伏神得日月生者一也；
伏神旺相者二也；
伏神得飞神生者三也；
伏神得动爻生者四；
伏神得遇日月动爻冲克飞神者五也；
伏神得遇飞神空破休囚墓绝者六也。
```

位置：`原典/增删卜易.md:1091-1093`

可入库规则：

1. 伏神得日月生，为有用。
2. 伏神旺相，为有用。
3. 飞神生伏，为有用。
4. 动爻生伏，为有用。
5. 日月动爻冲克飞神，为有用。
6. 飞神空、破、休囚、墓绝，为有用。

### 2. 《卜筮正宗》伏神得出四条

《卜筮正宗》“第九问 用神不现”：

```text
伏神得出者有四：
盖日月生者、日月持之者一也；
飞神生伏、动爻生者二也；
日月动爻冲克飞神三也；
飞神空破休囚墓绝于日者四也。
此四者有用之伏神也。
```

位置：`原典/卜筮正宗_古籍典藏.md:5414-5417`

可入库规则：

- 与《增删卜易》基本一致，可作为交叉验证。

### 3. 《增删卜易》无用伏神五条

《增删卜易》：

```text
又伏神终不得出者有五。
伏神休囚无气者一也；
伏神被日月冲克者二也；
伏神被旺相之飞神克者三也；
伏神墓绝于日月飞爻者四也；
伏神伏囚值空月破者五也。
此五者乃无用之伏神也，虽有如无，终不能出。
```

位置：`原典/增删卜易.md:1094-1095`

可入库规则：

1. 伏神休囚无气，为无用。
2. 伏神被日月冲克，为无用。
3. 伏神被旺相飞神克，为无用。
4. 伏神墓绝于日月飞爻，为无用。
5. 伏神休囚兼旬空月破，为无用。

### 4. 《卜筮正宗》伏神不得出四条

《卜筮正宗》：

```text
伏神不得出者亦有四：
休囚无气、日月克者一也；
飞神旺相、日月生助飞神克害伏神者二也；
伏神墓绝于日月及飞爻者三也；
伏神休囚兼旬空月破者四也。
此四者乃无用之伏神，虽有如无，终不得出。
```

位置：`原典/卜筮正宗_古籍典藏.md:5417-5419`

可入库规则：

- 与《增删卜易》五条基本一致。

## 六、伏神应期与出现

### 1. 《增删卜易》：飞不冲开亦枉然

《增删卜易》：

```text
伏无提携终徒耳，飞不冲开亦枉然。
凡用神不现，伏于卦中，须宜月建日辰，冲开飞神，
生合扶起飞神，即为有用。
```

位置：`原典/增删卜易.md:1574-1575`

可入库规则：

- 用神伏藏时，月建日辰冲开飞神，是伏神可用的重要条件。
- 月建日辰生合扶起相关爻，也可作提携条件。

### 2. 《增删卜易》：空下伏易于引拔

《增删卜易》：

```text
空下伏易于引拔。
伏神不空而飞神空，易于出现。
何也，飞神即空，乃上无压住之爻也，
而伏神再得月建日辰生扶拱合，脱然出矣。
```

位置：`原典/增删卜易.md:1576`

《增删卜易》又引《黄金策》：

```text
黄金策曰：空下伏神，易于引拨。
```

并解释：

```text
不独飞神空亡而伏神得出，
但得飞神临破休囚入墓而伏神皆易出也。
飞神逢破墓衰空，虽有若无，所以伏神易于出现。
```

位置：`原典/增删卜易.md:1092`

可入库规则：

1. 飞神空亡，伏神较易出现。
2. 飞神月破、休囚、入墓，也可视为飞神无力压伏。
3. 伏神还需得月建日辰生扶拱合，方能“脱然出”。

### 3. 《黄金策》：空下伏神易于引拔

《黄金策》：

```text
空下伏神易於引拔，制中弱主難以維持。
```

位置：`原典/黄金策.md:52`

可入库规则：

- 飞神空亡时，伏神容易被引拔。
- 但这只是条件之一，不可单独决定吉凶。

## 七、伏藏与出现

### 1. 《火珠林》：伏藏有气，只利暂时

《火珠林》“出现伏藏”：

```text
出现旺相，为久为远；
伏藏有气，只利暂时。
```

注中说：

```text
伏藏旺相，更看日辰透出，或伏世下，可取。
```

位置：`原典/火珠林.md:236-247`

可入库规则：

1. 出现且旺相，主久远。
2. 伏藏有气，也可取用，但多不如出现稳定。
3. 伏藏旺相，还要看日辰透出、伏世等条件。

### 2. 《黄金策》：伏藏有用

《黄金策》：

```text
出現無情，難遂青雲之志；
伏藏有用，終辭白屋之人。
```

位置：`原典/黄金策.md:888`

可入库规则：

- 出现之爻若无情，不一定吉。
- 伏藏之爻若有用，也可以成事。
- 这与《增删卜易》《卜筮正宗》“伏神有用/无用”规则一致。

## 八、风水涣例：逐卦飞伏定例

《卜筮正宗》逐卦飞伏定例中，《风水涣》如下：

```text
风水涣
━━━父母辛卯
━━━兄弟辛巳 世
(伏妻财酉金)━ ━子孙辛未
(伏官鬼亥水)━ ━兄弟戊午
━━━子孙戊辰 应
━ ━父母戊寅
```

后文说明：

```text
涣者散也，卦中缺妻财官鬼。
以离卦第三爻亥水官鬼伏于本卦第三爻午火之下，
午火是飞神，亥水是伏神，水克火，谓之伏克飞神为出暴；
以离卦第四爻酉金妻财伏于本卦第四爻未土之下，
未土是飞神，酉金是伏神，土生金，谓之飞来生伏。
```

位置：`原典/卜筮正宗_古籍典藏.md:960-969`

可入库规则：

1. 《风水涣》缺妻财、官鬼。
2. 官鬼亥水伏于三爻兄弟午火之下。
3. 妻财酉金伏于四爻子孙未土之下。
4. 三爻为伏克飞。
5. 四爻为飞来生伏。

## 九、Agent 可执行规则

### 1. 取伏神顺序

```text
本卦是否有用神
-> 有：正常取用神，不滥取伏神
-> 无：看日月是否可作为用神参考
-> 看变爻是否已有用神
-> 仍无：从本宫首卦取伏神
-> 以本卦同爻位为飞神
```

### 2. 飞伏关系

```text
飞生伏：伏神得生
飞克伏：伏神受制
伏生飞：伏神泄气
伏克飞：伏克飞，为出暴
飞伏比和：相助而吉
```

### 3. 伏神有用

```text
伏神得日月生
伏神旺相
飞神生伏
动爻生伏
日月动爻冲克飞神
飞神空破休囚墓绝
```

### 4. 伏神无用

```text
伏神休囚无气
伏神被日月冲克
伏神被旺相飞神克
伏神墓绝于日月飞爻
伏神休囚兼旬空月破
```

### 5. 出现与应期

```text
飞神空亡：伏神易出
飞神破墓衰空：伏神易出
月建日辰冲开飞神：伏神可用
伏神得月日生扶拱合：可被引拔
伏藏旺相且日辰透出：可取
```
