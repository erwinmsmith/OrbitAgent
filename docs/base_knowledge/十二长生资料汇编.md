## 三、六爻取用原则

### 1. 以五行论，不以天干阴阳分顺逆

六爻爻神以地支配五行，故本表按金、木、水土、火四组取长生。当前六爻资料中，《易隐》《卜筮正宗》《增删卜易》均以五行定局为主，不采用八字中按天干阴阳分顺逆的十二运体系。

### 2. 核心看“长生、墓、绝”，不机械套十二神吉凶

《卜筮正宗》说：“卦卦必用者长生，爻爻须究者墓绝，除三者之余，卦中俱弗重也。”见 `原典/卜筮正宗.md:1024`。

《增删卜易》说：“余得验者，只验生旺墓绝，其馀不验，不必用之。”见 `原典/增删卜易.md:959`。

因此 agent 中十二长生的核心状态应优先抽取：

| 状态 | 含义 | 断卦使用 |
|---|---|---|
| 长生 | 生发、有气、可起 | 用神、元神遇之可作有气；忌神、鬼爻遇之则凶势有根 |
| 帝旺 / 旺 | 力足、势盛 | 《增删卜易》将“旺”列入生旺墓绝经验口径 |
| 墓 | 藏滞、入库、暗昧 | 需看旺衰、冲开、是否回头克；不可一概凶 |
| 绝 | 气断、难续 | 可待长生、生旺、原神救助；不可脱离扶抑判断 |

### 3. 日辰可查十二长生，月建不宜按十二神机械断

《卜筮正宗》明确：“长生、沐浴、冠带这十二神与日辰固有干系，与月建上不过只论得月破、休囚旺相生克。”见 `原典/卜筮正宗.md:1399-1400`。

所以：

- 日辰层：可标注某爻对日辰处于长生、墓、绝等状态。
- 月建层：优先按月令旺相休囚、月破、生克论，不应直接说“月上衰病死墓即凶、长生帝旺即吉”。

### 4. 动爻化出之爻，要先看生克冲合、进退、伏吟反吟

《卜筮正宗》反复说明，沐浴、冠带、临官、帝旺、衰、病、死、胎、养等，不可脱离生克冲合、进神退神、伏吟反吟而断。见 `原典/卜筮正宗.md:1141-1148`、`原典/卜筮正宗.md:1386-1388`、`原典/卜筮正宗.md:1581-1584`。

原典摘录：

> 凡卜卦，爻遇长生、沐浴、冠带、临官、帝旺、衰、病、死、绝、胎、养，卦中所重者长生、墓、绝，其沐浴、冠带等七件，各有合冲生克扶拱进退神分别。
>
> 生克制化合冲之间，神机报在，岂长星元以胎养半吉之祥，以衰病半凶之祸。
>
> 大凡卦中爻象，只讲得长生、墓、绝三件，向日辰是问，就是变出来的也要看，唯沐浴、冠带、临官、帝旺、衰、病、死、胎、养不可向变出之爻是问。
>
> 若化出来的，当以生克冲合、进神退神、反吟伏吟论也。
>
> 长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养，此十二神，卦中唯是长生、墓、绝三件，卦卦看，爻爻要查，其余沐浴、冠带、临官、帝旺、衰、病、死、胎、养各神，俱各有生克冲合、进神退神、伏吟反吟论，不可执疑于养主狐疑，病主伤损，胎主勾连。

因此 agent 不应输出：

- “化胎半吉”
- “化养半吉”
- “化病半凶”
- “化沐浴必败”

应先判定：

- 化出爻与本爻是回头生、回头克、进神、退神、合、冲、伏吟、反吟；
- 再参考是否为长生、旺、墓、绝。

### 5. 长生不必然吉，墓绝不必然凶

《增删卜易》举例说明，金虽长生在巳，但金爻休囚无气又遇巳午火多时，论克不论生；土爻虽绝于巳，若土爻旺相或得生扶，再遇巳火反能生土，论生不论绝。见 `原典/增删卜易.md:964`。

因此十二长生必须服从：

1. 用神、元神、忌神、仇神身份；
2. 月建、日辰、动爻、变爻的生克制化；
3. 旺衰、空破、合冲、墓绝等综合状态。

## 四、程序化字段建议

十二长生可作为爻状态字段，不应替代旺衰总判。

```json
{
  "twelve_stage": {
    "by_day": "长生",
    "by_changed_branch": "墓",
    "source_table": "易隐_长生定局",
    "interpretation_level": "辅助状态"
  }
}
```

建议实现：

1. 根据爻支五行取所属组：金、木、水土、火。
2. 用日辰地支查 `by_day`。
3. 若爻发动，则用变爻地支查 `by_changed_branch`。
4. 月建不输出十二长生断语，只输出月令旺衰、月破、生克。
5. 最终吉凶不由 `twelve_stage` 单独决定。

## 五、校验规则

- 表中每个五行组必须覆盖 12 地支，且无重复。
- 金、木、水土、火四组的长生位必须分别为：巳、亥、申、寅。
- 墓位必须分别为：金丑、木未、水土辰、火戌。
- 绝位必须分别为：金寅、木申、水土巳、火亥。
- 土随水土同宫，采用“水土长生在申”的六爻口径。
- 若规则结果与月建旺衰冲突，优先按月建旺衰、生克、月破处理。

## 六、使用边界

- 本文只整理十二长生基础表和六爻使用规则。
- 涉及具体吉凶时，必须进入旺衰、用神、元神忌神、空破、动变、合冲等综合判断。
- 本文不采用八字命理中按十天干阴阳顺逆排十二运的规则。
- 本文不采用“胎养半吉、衰病半凶”等机械断法。
